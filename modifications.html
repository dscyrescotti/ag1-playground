BFS modifications: the layered-graph method

Don't change BFS — change the graph. Build a new directed graph $H$ whose vertices are pairs (original vertex, what you need to remember), run the lecture BFS on $H$ unchanged, and read the answer back in $G$. Every example from Tutorial: BFS modifications below, each with a demo you can edit and step through.

The recipe

  1. Describe a valid solution as a sequence. Write the walk as the word of its edge colours (e.g. $BBRBR$) or of the vertex types it visits. The condition becomes "the word belongs to a language $L$".
  2. Find the state. Ask: what is the least I must remember about the prefix so far to decide how it may continue? Number of red edges so far, parity, the phase, the set of keys collected… That finite set $Q$ is the set of states of an automaton for $L$.
  3. Build the layers. One copy of $V$ for each state: $V(H) = V \times Q$. Write $v_q$ for the copy of $v$ in layer $q$.
  4. Build the edges. For every edge $\{u,v\}$ of colour $c$ and every state $q$, add the directed edge $(u_q, v_{\delta(q,c)})$ — and also $(v_q, u_{\delta(q,c)})$, since $G$ is undirected. If the move is forbidden ($\delta$ undefined, the "garbage state"), add nothing.
  5. Source and target. Start at $s_{q_0}$. If several states are accepting, add a new vertex $t^\ast$ with edges $(t_q, t^\ast)$ for every accepting $q$ (the answer is then $\operatorname{dist}_H - 1$), or just take the minimum over the accepting copies.
  6. Run plain BFS on $H$ from $s_{q_0}$. Project the path back to $G$ by dropping the subscripts.
  7. Prove it with the three standard claims (below), then state the complexity.

Proof template

Claim 1 ($G \Rightarrow H$). Each valid $s$-$t$-walk of length $k$ in $G$ gives an $s_{q_0}$-$t_{q_f}$-walk of length $k$ in $H$: follow the automaton along the walk, and every step is an edge of $H$ by construction.

Claim 2 ($H \Rightarrow G$). Each $s_{q_0}$-$t_{q_f}$-path in $H$ projects to a walk of the same length in $G$. It is valid because the layer index encodes the state exactly, and only accepting layers contain the target.

Claim 3 (shortest ↔ shortest). If the BFS path had length $k$ but a valid walk of length $k' < k$ existed, Claim 1 would give a walk in $H$ of length $k'$, which contains a path of length at most $k'$ — contradiction with BFS optimality.

Path or walk?

The projection of a path in $H$ may repeat vertices of $G$ (it visits $v_0$ and later $v_2$, say). Whether that matters depends on the condition:

  • Monotone conditions — "at most one red", "blue before red", "at most $k$ costly". Cutting out a cycle never breaks validity, so a shortest valid walk is automatically a path. You may ask for a path.
  • Exact counts / parity — "exactly three red", "an even number of blue". Cutting a cycle may remove a red edge or flip a parity, and a valid path might not exist at all. The problem must ask for a walk.

Complexity

$|V(H)| = |Q|\cdot|V|$ and $|E(H)| \le 2|Q|\cdot|E|$, so BFS on $H$ runs in $\mathcal{O}\big(|Q|\,(|V|+|E|)\big)$. Combining two conditions = product of automata: $|Q| = |Q_1|\cdot|Q_2|$.

In every demo, click an edge to swap its colour (or click a vertex to change its type), then press Step to watch BFS run on $H$. The highlighted path in $H$ is projected back onto $G$ underneath.

1

Blue edges before red edges

path · 2 layers

$G=(V,E)$ is connected and undirected, $E = E_B \mathbin{\dot\cup} E_R$. Find a shortest $s$-$t$-path in which all blue edges come before all red edges.

State

Which phase are we in: still blue ($B$), or already red ($R$)?

Layers

$v^B$ and $v^R$ for every $v \in V$.

Edges of $H$

$\{u,v\} \in E_B$: $(u^B, v^B)$.
$\{u,v\} \in E_R$: $(u^B, v^R)$ and $(u^R, v^R)$.
No edge goes from layer $R$ back to $B$.

Source → target

$s^B \to t^\ast$, with $(t^B,t^\ast), (t^R,t^\ast)$. Answer $= \operatorname{dist}_H(s^B,t^\ast) - 1$.

Why only from $s^B$? An all-red solution starting with $\{s,w\}$ is also found via the cross edge $(s^B, w^R)$, so we never need to start in $s^R$.

Path, not just walk. If the projected walk revisits a vertex, it is the blue part $P$ and the red part $Q$ meeting at some $w$; go along $P$ to the first such $w$ and then along $Q$. This is shorter and still valid, so a shortest valid walk is a path.

Alternative without layers: BFS on $(V,E_B)$ from $s$ and on $(V,E_R)$ from $t$, then minimise $d_B(s,v) + d_R(v,t)$ over $v$. Time: $\mathcal{O}(|V|+|E|)$.

2

At most one red edge

path · 2 layers

Find a shortest $s$-$t$-path using at most one red edge.

State

How many red edges have been used: $0$ or $1$.

Layers

$v_0, v_1$ for every $v \in V$.

Edges of $H$

$\{u,v\}\in E_B$: $(u_0,v_0)$ and $(u_1,v_1)$.
$\{u,v\}\in E_R$: $(u_0, v_1)$ only.
A second red edge would need $(u_1, v_2)$, which doesn't exist.

Source → target

$s_0 \to t^\ast$ via $(t_0,t^\ast),(t_1,t^\ast)$.

Path. "At most one" is monotone: cutting a cycle out of a valid walk leaves at most one red edge, so a shortest valid walk is a path.

Alternative: BFS on blue edges from $s$ and from $t$, then $$q = 1 + \min_{\{u,v\}\in E_R} \big(d_B(s,u) + d_B(v,t)\big),\qquad \text{answer} = \min\{q,\ d_B(s,t)\}.$$ (Try both orientations of each red edge.) Time: $\mathcal{O}(|V|+|E|)$.

3

Exactly three red edges

walk · 4 layers

Find a shortest $s$-$t$-walk using exactly three red edges.

State

Red edges so far: $i \in \{0,1,2,3\}$.

Layers

$v_0, v_1, v_2, v_3$.

Edges of $H$

$\{u,v\}\in E_B$: $(u_i,v_i)$ for $i=0,\dots,3$.
$\{u,v\}\in E_R$: $(u_i, v_{i+1})$ for $i=0,1,2$.

Source → target

$s_0 \to t_3$ — a single target, so no $t^\ast$ is needed.

Why a walk? Cutting a cycle could delete a red edge and destroy validity, and maybe no valid path exists at all. In the default demo the answer goes through $a$ twice — once in layer 0 and once in layer 2 — which is a path in $H$ but not in $G$.

Correctness, shortest part. In a shortest valid walk $S$, each segment between two consecutive red edges is a path (otherwise cut the blue cycle — still 3 red edges, shorter). Each segment therefore lives in a single layer as a path, so $S$ maps to a path of the same length in $H$. Time: $\mathcal{O}(4(|V|+|E|)) = \mathcal{O}(|V|+|E|)$.

4

Even number of blue edges

walk · 2 layers

Find a shortest $s$-$t$-walk using an even number of blue edges.

State

Parity of blue edges so far: $0$ = even, $1$ = odd.

Layers

$v_0, v_1$.

Edges of $H$

$\{u,v\}\in E_R$: $(u_0,v_0)$, $(u_1,v_1)$ — red stays in its layer.
$\{u,v\}\in E_B$: $(u_0,v_1)$, $(u_1,v_0)$ — blue switches layer.

Source → target

$s_0 \to t_0$.

Note. Here edges between the layers go both ways — parity can return to even. The layered graph is not "one-way" in general; that was only true for monotone conditions.

Walk: a path with even blue count may not exist (a triangle $s$–$u$–$t$ with one blue edge, say). Time: $\mathcal{O}(|V|+|E|)$.

5

Even blue and exactly three red

walk · 2 × 4 = 8 layers

Find a shortest $s$-$t$-walk with an even number of blue edges and exactly three red edges.

State

The pair $(p, i)$: blue parity $p\in\{e,o\}$ and red count $i\in\{0,\dots,3\}$ — the product of the automata from Ex. 3 and Ex. 4.

Layers

$v^{p,i}$ — eight copies of $V$.

Edges of $H$

$\{u,v\}\in E_B$: $(u^{p,i}, v^{\neg p,i})$ for all $p$, $i$.
$\{u,v\}\in E_R$: $(u^{p,i}, v^{p,i+1})$ for $i \le 2$.

Source → target

$s^{e,0} \to t^{e,3}$.

Takeaway. Conditions combine by multiplying state sets: $|Q| = 2 \cdot 4 = 8$. The proof is Ex. 3 + Ex. 4 together: each coordinate of the layer index tracks its own quantity exactly. Time: $\mathcal{O}(8(|V|+|E|))$.

6

Alternating colours

walk · 2 layers + start

Find a shortest $s$-$t$-walk whose edge colours alternate (blue is always followed by red, and red by blue).

State

The colour of the last edge: $B$ or $R$ (it fixes what the next one must be).

Layers

$v^B$ ("last was blue, next must be red") and $v^R$.

Edges of $H$

$\{u,v\}\in E_B$: $(u^R, v^B)$.
$\{u,v\}\in E_R$: $(u^B, v^R)$.
Every edge of $H$ goes between the layers; there are none inside a layer.

Source → target

Target $t^\ast$ with $(t^B,t^\ast),(t^R,t^\ast)$.

Following the hint. Starting with blue: pretend the previous edge was red, so start at $s^R$. Any first colour: add a new source $s^\ast$ with edges $(s^\ast, w^B)$ for $\{s,w\}\in E_B$ and $(s^\ast, w^R)$ for $\{s,w\}\in E_R$. This is the "start" layer in the demo, which contains only $s$. Running BFS twice (from $s^R$ and from $s^B$) and taking the minimum also works. Time: $\mathcal{O}(|V|+|E|)$.

7

At most $k$ costly vertices

path · $k+1$ layers

A subset $W \subseteq V$ is costly. Find a shortest $s$-$t$-path visiting at most $k$ vertices of $W$, in time $\mathcal{O}\big((k+1)(|V|+|E|)\big)$.

State

Number of costly vertices visited so far: $i\in\{0,\dots,k\}$. The condition is on vertices, so the transition depends on the vertex we enter.

Layers

$v_0,\dots,v_k$.

Edges of $H$

For $\{u,v\}\in E$, in both directions:
$v\notin W$: $(u_i, v_i)$;
$v\in W$: $(u_i, v_{i+1})$ for $i<k$.

Source → target

$s_0$, or $s_1$ if $s\in W$. Target $t^\ast$ from all $t_i$.

Path. Cutting a cycle never increases the count, so a shortest valid walk is a path. Time: $H$ has $(k+1)|V|$ vertices and at most $2(k+1)|E|$ edges, giving $\mathcal{O}((k+1)(|V|+|E|))$ as required. Click vertices to toggle them in or out of $W$.

8

Keys and doors

walk · 2 layers

Vertices $K$ hold keys and vertices $D$ hold doors. A door can't be entered before at least one key has been collected. Find a shortest $s$-$t$-walk.

State

Do we hold a key yet? $0$ = no, $1$ = yes.

Layers

Layer 0: $G$ with the doors locked (no edge may enter $d_0$ for $d\in D$). Layer 1: all of $G$.

Edges of $H$

Entering $v$ from layer 0: if $v\in D$, no edge; if $v\in K$, $(u_0, v_1)$; otherwise $(u_0,v_0)$.
Layer 1: $(u_1,v_1)$ for every edge.

Source → target

$s_0$ ($s_1$ if $s\in K$) $\to t^\ast$ from $t_0, t_1$.

Walk: you may have to walk to a key and come back the same way — that repeats vertices in $G$ but not in $H$ (the way out is in layer 0, the way back in layer 1). Time: $\mathcal{O}(|V|+|E|)$. Click a vertex to cycle: none → key → door.

9

Collect all $\ell$ key types

walk · $2^\ell$ layers

Keys of type $j$ lie in $\kappa_j\subseteq V$, for $j=1,\dots,\ell$. Vertex $t$ can be entered only after collecting at least one key of every type. Find a shortest such walk in time $\mathcal{O}\big(f(\ell)(|V|+|E|)\big)$.

State

Which types we already have: a subset $S\subseteq\{1,\dots,\ell\}$. A count isn't enough, because two keys of the same type don't help.

Layers

$v_S$ for each of the $2^\ell$ subsets $S$ (store $S$ as an $\ell$-bit mask).

Edges of $H$

For $\{u,v\}\in E$, both directions: $(u_S, v_{S\cup \tau(v)})$, where $\tau(v)=\{j : v\in\kappa_j\}$.
Exception: no edge into $t_S$ unless $S = \{1,\dots,\ell\}$.

Source → target

$s_{\tau(s)} \to t_{\{1,\dots,\ell\}}$.

Time: $|V(H)| = 2^\ell|V|$, $|E(H)|\le 2^{\ell+1}|E|$, so $f(\ell)=2^\ell$. The problem is FPT in $\ell$. Demo with $\ell = 2$: click a vertex to cycle none → $\kappa_1$ → $\kappa_2$ → both.

10

Minimise the number of red edges

path · contraction

Find an $s$-$t$-path that uses as few red edges as possible (its length doesn't matter).

BFS minimises the number of edges, so we must make blue edges free. Layers don't help here; this is a different graph modification: contract the blue edges.

Vertices of $H$

The connected components $C_1,\dots,C_m$ of the blue graph $(V,E_B)$, found by BFS on blue edges only.

Edges of $H$

$\{C(u), C(v)\}$ for every red edge $\{u,v\}$ with $C(u)\ne C(v)$. Red edges inside a component are useless.

Answer

$\operatorname{dist}_H(C(s), C(t))$ = minimum number of red edges.

Reconstruct

Take the red edges on the $H$-path, and inside each component join the entry and exit vertices by a blue BFS path.

Correctness. An $s$-$t$-path in $G$ with $r$ red edges crosses $r$ red edges between components, so $\operatorname{dist}_H \le r$. Conversely, an $H$-path of length $r$ lifts to a walk in $G$ with $r$ red edges, because components are blue-connected. Shortcutting cycles only removes edges, so it becomes a path with at most $r$ red edges. Time: $\mathcal{O}(|V|+|E|)$. (Equivalent: 0-1 BFS with a deque, where blue edges have weight 0 and are pushed to the front.)

11

Three water containers

state-space BFS

Containers have capacities $n_1,n_2,n_3$. Operations: fill one to the top, empty one, or pour from one into another until the source is empty or the target is full. Reach a configuration where some container holds exactly $K$ litres.

This is the layered idea at its most extreme: there is no input graph at all, and the whole graph is states.

Vertices

Configurations $(a,b,c)$ with $0\le a\le n_1$, $0\le b\le n_2$, $0\le c\le n_3$ — at most $(n_1+1)(n_2+1)(n_3+1)$ of them.

Edges (directed!)

One per operation: 3 fills, 3 empties, 6 pours, e.g. pouring $1\to 2$ moves $x=\min(a,\,n_2-b)$: $(a,b,c)\to(a-x,\,b+x,\,c)$. Operations aren't reversible, so $H$ is directed.

Source → target

$(0,0,0) \to t^\ast$, with an edge from every configuration where $a=K$, $b=K$ or $c=K$.

Time

$\mathcal{O}\big((n_1+1)(n_2+1)(n_3+1)\big)$ — at most 12 edges per vertex, generated on the fly. That is pseudo-polynomial (the input has size $\Theta(\log n_i)$).

BFS gives the minimum number of operations; if $t^\ast$ is unreachable, no solution exists.
